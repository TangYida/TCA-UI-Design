# 本地字体

- EB Garamond：Regular、Italic、SemiBold
- Libre Baskerville：Regular、Bold
- Roboto：Variable 100–900、Variable Italic 100–900

字体来自 Google Fonts 的对应发行文件，均按 SIL Open Font License 发布。Roboto 两个可变字体文件于 2026-08-21 从 Google Fonts 官方仓库的 `ofl/roboto` 下载，并作为导航、元数据、标签和控件的共享无衬线字体。生产打包时应保留字体许可，并根据实际字符范围进行子集化；不要在这里放编辑照片。
