# The China Academy — Article Layout Redesign

## Typography
- Display/body serif: EB Garamond
- CJK fallback: Noto Serif SC
- UI/navigation: Inter
- Body size: 22px desktop / 20px mobile
- Body line-height: 1.72 desktop / 1.68 mobile
- Reading measure: max-width: 80ch

## Hierarchy
- H1: 52–92px responsive
- H2: 34–49px responsive, large vertical spacing
- Inline emphasis: italic, no bold-heavy interruption
- Long quotation: 100% italic, larger type, horizontal hairlines instead of boxed quote
- Images: break out beyond the reading measure to create pacing

## Interaction
- Reading progress indicator
- Sticky section navigation on desktop
- Subtle reveal animation
- Reduced-motion support
